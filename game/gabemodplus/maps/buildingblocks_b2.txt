Just extract the map to your hl2/maps folder

then load up HL2 and load the map thru the console by typing map buildingblocks. The object of this map it to make things from the Blocks and other objects in the map.


there are now 12 Spawn stations in the map each spawn differant things. If you run out of blocks you can spawn more at one of the spawning stations
